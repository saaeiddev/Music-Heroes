# MUSIC HEROES

**An Interactive 3D Journey Through Music**

MUSIC HEROES is a cinematic black-and-gold educational web experience for exploring musical instruments in real time.

## Features

- Interactive real-time 3D instrument viewer
- 11 instruments across multiple musical families
- Drag to rotate and wheel/pinch to zoom
- Instrument search and family navigation
- Learn, Sound and 360° Explore modes
- Interactive electric-guitar hotspots
- Synthesized Web Audio demonstrations with no autoplay
- Responsive desktop, tablet and mobile layout
- GitHub Pages deployment workflow

## Technology

HTML5, CSS3, JavaScript ES Modules, Three.js, OrbitControls and Web Audio API.

## Deployment

This repository is configured for GitHub Pages using GitHub Actions.
